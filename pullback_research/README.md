# 급등(+15%) 후 눌림 매수 연구

D일 종가 등락률 ≥ +15% 종목을 D+1일부터 최대 20거래일 관찰하며, 여러 "눌림" 진입 규칙 × 익절/손절/보유기간 조합을 백테스트한다.

## 진입 규칙 계열 (총 139개)
| 계열 | 내용 |
|---|---|
| base | D 종가 / D+1 시가 / D+k 종가 매수 (눌림 없이 사는 기준선) |
| pct | D 종가 대비 -3/5/7/10/15/20/25% 지정가 |
| fib | 장대봉(전일종가→D종가) 75/61.8/50/38.2/25/0% 지점 지정가 |
| candle | D 시가, D 몸통 중간 지정가 |
| ma | 3/5/10/20일 이평 터치 지정가 (전일까지 이평값) |
| rev | 고점 대비 -x% 눌림 후 전일 고가 돌파 → 다음날 시가 / 양봉 종가 |
| vol | 거래량이 D일의 15/25/40% 이하로 마르고 장대봉 절반 지지 → 종가 |
| combo | 눌림 + 거래량 급감 + 전일 고가 돌파 + 장대봉 하단 유지 |

각 규칙에 관찰기간 W = 5/10/20일, 청산은 익절 5~30%/없음 × 손절 3~15%/없음 × 보유 1~20일.

## 과최적화 방지
- 2022-01-01 이전(IS)에서 고르고 이후(OOS)에서 검증
- 진입규칙별 "IS 최적 청산"과 "청산조합 전체 중앙값"을 같이 봄
- 보수적 체결: 같은 날 익절·손절 동시 터치 시 손절 우선, 갭은 시가 체결, 왕복비용 0.3%
- 랜덤워크(엣지 0) 합성데이터로 엔진 검증 완료 → 평균 수익 ≈ 0, t값 ≈ N(0,1)
